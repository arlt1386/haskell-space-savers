# haskell-space-savers

**Description:** 

This is the Haskell Space Savers project. It is a text-based adventure game written in Haskell. This will take you on a grand adventure through space. You will be at the helm of your own destiny.

Strap in, Captain! The galaxy is vast, the fuel is limited, and every choice you type could mean glory or a very dramatic explosion. Dodge asteroid fields, make first contact with strange alien civilizations, and rescue stranded crews before time runs out. Will you play it safe, or take the daring shortcut?

Built with pure functional programming, because even the cosmos deserves clean, well-typed code. Launch the game, type your commands, and see where the stars take you.



**How to Run the Game:**

Option 1:

Open up a terminal and go to where the Main.hs file is located. Type in "runghc Main.hs" and let the game begin. Enjoy the experience.

Option 2:

Use ghci, load the main file and run it. Enjoyment of the exerience is required.
